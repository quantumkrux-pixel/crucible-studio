Installing Crucible3D

A couple of things to know the first time you run the desktop edition.

Unknown developer warning

The app isn't code-signed yet. Windows may require More info → Run anyway. On macOS, right-click the app and choose Open → Open. Linux AppImages can be launched directly.

Linux · AppImage

Make the AppImage executable, then launch it with chmod +x Crucible3D-1.3.0.AppImage followed by ./Crucible3D-1.3.0.AppImage. If FUSE is unavailable, use your distro's package manager or --appimage-extract-and-run.
